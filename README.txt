# BALANTANG JAYA GLOBAL
## Company Profile & Portfolio Website

Official company portfolio website for **Balantang Jaya Global**, a
Drilling & Construction company.

The website is designed as a responsive corporate portfolio showcasing:

- Company profile
- Drilling & construction services
- Project experience
- Drilling equipment fleet
- HSE & quality commitment
- Project gallery
- Company capabilities
- Client / project partner information
- Contact information

# 2. Website Purpose

The purpose of this website is to provide a professional digital
company profile for Balantang Jaya Global.

The website is intended for:

- Potential clients
- Project owners
- Contractors
- Business partners
- Procurement teams
- Project management teams
- HSE teams
- Recruitment / manpower stakeholders

The website should communicate:

> Reliable Solutions. Safe Execution. Quality Results.

The site should present Balantang Jaya Global as a professional
drilling and construction company with strong emphasis on:

1. Operational capability
2. Equipment readiness
3. Project execution
4. HSE
5. Quality
6. Professional manpower
7. Project coordination

# 4. Technology Stack

This website intentionally uses a lightweight technology stack.

## Frontend

### HTML5

Used for:

- Page structure
- Navigation
- Sections
- Cards
- Tables
- Forms
- SEO metadata

### CSS3

Used for:

- Layout
- Responsive design
- Colors
- Typography
- Animations
- Cards
- Buttons
- Mobile navigation

### JavaScript

Used for:

- Mobile navigation
- Scroll interactions
- Animation triggers
- UI interactions
- Dynamic visual effects

No frontend framework is required.

The project does NOT require:

- React
- Vue
- Angular
- Node.js
- PHP
- MySQL

This keeps the website simple and easy to maintain.

GitHub Pages supports static HTML, CSS and JavaScript websites directly
from repositories. It does not provide server-side PHP/Python processing
for the site.
